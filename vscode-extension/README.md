# Jokotin Language

Resaltado de sintaxis y snippets para archivos `.jok`, el lenguaje de backend
Jokotin.

Creado por el ingeniero Johan Antonio Mancebo Lebron, también conocido como
JohansitoDev. Hecho con mucho amor.

## Uso

- Abre un archivo `.jok` para activar el resaltado de sintaxis.
- Selecciona el tema **Jokotin Dark** desde **Preferences: Color Theme**.
- Selecciona el tema de iconos **Jokotin Icons** desde **Preferences: File Icon Theme**.
- Escribe `get`, `post`, `require` o `jokserver` para insertar un snippet.
